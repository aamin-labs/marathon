# Breeze plan, 18-week version

Source: *Marathon Excellence for Everyone (Metric Edition)* by John Davis, pages 189–223. Transcribed from the Kindle screenshots in `breeze/` for personal use. This file holds the weekly workout tables only; the book's notes on how to run each session are not copied here, so read those in the book.

`breeze-80.txt` is this plan resolved to single numbers for the app. This file is the reference with the book's ranges intact.

## How to read it

- **Two versions share one table.** Breeze 65 peaks at 65 km/week, Breeze 80 at 80 km/week. Goal mileage is written `65 version / 80 version`.
- **All running counts toward mileage**: warm-ups, cool-downs, strides.
- **% 5k** is a percentage of current 5K pace. **% MP** is a percentage of marathon pace. Both are percentages of speed, so a higher number is faster.
- **WU** = 2 km progressive warm-up + 4 strides. **CD** = easy cool-down.
- **Difficulty** is the book's target effort out of 10. Blank means an ordinary easy day.
- **◆** = revise your current fitness estimate at the end of that week.
- Phases: general (weeks 1–10), marathon-supportive (11–14), marathon-specific (15–18).
